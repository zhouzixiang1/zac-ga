## 2. 输入、基线与物理模型

- ZAC18 包含 ZAC 论文的 18 个基准电路；QMAP154 包含 MQT QMAP 的 154 个示例输入。后者按规范化 QASM 身份合并后为 151 个不同电路。原始文件清单与独立统计对象分别保留。
- 基线为 Lin 等人的 ZAC 和 Stade 等人的 routing-aware placement；后者使用 MQT QMAP v3.2.0。三种方法使用相同的规范化输入及门序列；基线按各自原生编译输出评分。GA-LK 执行候选占位、轨迹相容性与非目标交点检查，验证要求不回溯改写基线算法。
- 架构包含 `100 × 100` 个存储区 SLM 阱位、`7 × 20` 个纠缠区门位对和一个 `100 × 100` 的 AOD 阵列。
- 采用 ZAC 文献中的模型及评估参数：`f1 = 0.9997`、`f2 = 0.995`、`fexc = 0.9975`、`ftran = 0.999`、`T2 = 1.5 × 10^6 μs`。阱转移逐原子计数，输运及空闲时间进入相干损失，单比特门的执行时间保留。
- 重排批次是满足 AOD 约束的串行批次数；重排时延是各批次关键轨迹时间的累积。二者是物理执行指标，与主机上的编译时间分开统计。

## 3. 默认配置与重复运行

总体比较、动态前瞻对照和遗传搜索对照均采用原有的层序加权模拟退火初始化。动态 GA-LK 默认前瞻上限为 `H = 8`，权重 `alpha = 0.5`、层距衰减 `rho = 0.7`、停止阈值 `epsilon = 0.05`。`H` 只计当前双比特层之后的层；实际预测长度还受剩余层数、衰减停止条件及规模预算限制。

默认主搜索编码评价上限为 576，精确枚举上限为 512，种群规模为 8、迭代代数为 6；每个回迁原子的候选存储位上限为 6，每个编码保留的分配数为 4。大规模边界的收缩规则以论文求解预算表与冻结配置为准，不能把上限当作每次实际评价次数。

| 实验 | 运行设置 | 电路内统计 |
|---|---|---|
| 主结果中的 ZAC、ICCAD/QMAP | 每电路各一个已验证的原生结果，种子记录为 0 | 使用该结果，运行数为 1 |
| 主结果中的 GA-LK | 随机种子 0、1、2 | 对数保真度和各物理指标分别取三种子的中位数 |
| 动态 `H = 0`、`H = 8` | 每配置均为种子 0、1、2 | 各配置先取三种子中位数，再作逐电路比较 |
| 同目标确定性贪心 | 确定性配置，种子记录为 0，运行一次 | 与 `H = 8` 遗传配置的三种子中位数比较 |
| 参数配置 | 默认值及八个调整配置均使用种子 0 | 逐电路与默认配置求比值 |
| 串行编译计时 | 每方法固定种子 0，预热后重复运行三次 | 每电路取三次编译时间的中位数 |
| 初始化前瞻扩展 | 每电路种子 0、1、2，每种子有三个匹配配置 | 对数保真度和批次先在种子间取算术均值 |

随机种子重复与计时重复是两套记录。基线的主结果不是三种子结果；三个计时重复也不增加独立电路样本数。

## 4. 统计对象与完整性

主质量比较要求三种方法均完成全部约定运行，且每个原子的模型相干项满足 `tq < T2`。ZAC18 的共同有效集合含 18 个不同电路；QMAP154 含 122 个共同有效输入文件，合并等价输入后为 120 个不同电路。QMAP 的等价输入在各身份簇内合并，对数保真度取簇内均值，再以一个簇作为一个统计对象。

主结果保真度为电路间几何均值，批次与重排时延为电路间算术均值。完成数按全部输入文件统计，与质量比较的共同有效分母不同。原始状态、超时和模型适用域之外的记录均保留，不以零替代，也不因缺失而切换到其他运行。

受控对照先求每电路的保真度比，再跨共同有效电路取几何均值。原参数配置对照的保真度比和编译时间比也分别按电路求比后取几何均值，但有效集合不同，分别为 10 和 12 个电路。当前表 IV 的五档前瞻比较使用第 9 节的独立汇总，保真度与批次共用同一有效集合。

## 5. 两项动态对照

两项对照共用预定的 48 个输入：全部 ZAC18，以及按双比特门数分层的 30 个 QMAP 输入。QMAP 三层为不超过 300、301–1500 和超过 1500 个双比特门；每层按规范化输入 SHA-256、文件名排序选前 10 项。规则与清单在运行前冻结，不按新结果挑选。

| QMAP 分层 | 冻结电路清单 |
|---|---|
| 不超过 300 | `4gt11_84`、`4gt5_76`、`majority_239`、`qe_qft_4`、`one-two-three-v0_98`、`rd32_270`、`4mod7-v0_94`、`ground_state_estimation_10`、`alu-bdd_288`、`4gt10-v1_81` |
| 301–1500 | `squar5_261`、`adr4_197`、`sf_276`、`cm152a_212`、`sqrt8_260`、`con1_216`、`z4_268`、`rd53_130`、`hwb5_53`、`rd53_251` |
| 超过 1500 | `clip_206`、`hwb8_113`、`urf3_155`、`urf4_187`、`plus63mod8192_164`、`rd73_252`、`9symml_195`、`sym9_193`、`root_255`、`hwb9_119` |

**遗传搜索。** 固定 `H = 8`、联合决策变量、目标函数、存储位候选域、物理约束及评价预算，只把适用大规模边界的遗传搜索替换为逐坐标确定性贪心及局部精修。保真度有效且至少出现一个遗传搜索适用边界的 38 个电路进入该比较。此对照检验同一联合目标下的搜索策略，不是联合决策与顺序决策的对照。

**多层前瞻。** 将上限 `H` 从 0 改为 8，其余配置、搜索预算及存储位域保持一致。`H = 8` 包含有序未来层代价、预测末端的回迁代价以及由可见未来层形成的近期复用驻留优先规则；`H = 0` 的未来层及对应驻留保护集合为空，保留当前边界物理约束和候选构造。39 个完整且保真度有效的电路进入比较。结果反映整套前瞻配置的变化，不单独分离其中每个组成项。

全部 48 项及各配置状态见 [ablation.csv](../../ZAC_zzx/results/paper_zh_v2/ablation.csv)。GA-NL 是历史结构变体，与本处共享参数的 `H = 0` 配置不同，不互相替代。

## 6. 逐电路展示与物理分量

典型电路表展示高增益案例，不作为总体分布的替代。每个基准集选两项：先要求两种基线中较高的保真度不低于 0.05，再按 GA-LK 相对该值的对数保真度增幅排序。四项为 QFT-18、Ising-42、Ising-16 和 Ising-13；表内仍分别列出两种基线的绝对保真度。

QFT-18 的分量分析固定以 ZAC 为比较对象。阱转移、空闲原子受激和相干项的变化来自 [fig6_mechanism.csv](../../ZAC_zzx/results/paper_zh_v2/fig6_mechanism.csv)，正值表示对应的对数保真度改善。转移次数、分量值和整体保真度均保留各自冻结的电路内汇总口径；不能把分别取中位数的多个分量强行相加为某一次实际运行。该例说明完整 GA-LK 编译结果的损失组成，不单独归因于遗传搜索或前瞻。

## 7. 初始化前瞻的独立扩展

初始化扩展的预定集合为动态前瞻对照中的 39 个有效电路。复用旧九电路先导中匹配的 7 项，并补齐其余 32 项；旧先导额外的 `ex1_226` 和 `cm82a_208` 只保留在原先导中。39 项的来源链接、117 个电路–种子任务及未完成记录均保留，旧 Ising 超时未重跑替换。

- [旧先导协议](../../ZAC_zzx/results/initial_lookahead_v1/nine-family-h0-h2-sa-k4-rho07-b32-seed012-v1/protocol.json)与[扩展协议](../../ZAC_zzx/results/initial_lookahead_v1/dynamic39-missing32-h0-h2-sa-k4-rho07-b32-seed012-p3-v1/protocol.json)在各阶段执行前分别封存。扩展协议保存新增清单、旧结果链接、输入与源码快照。
- 每个电路–种子只生成一次原始模拟退火布局，再构造包含该布局及确定性扰动的四候选池。`Hinit = 0` 与 `Hinit = 2` 共享候选，分别评价首个双比特层，以及首层和最多两个后续层；折扣 `rho = 0.7` 按逐层增量作用。
- 前缀评价使用实际单比特执行时间、可行路由与逐原子保真度账本；内层主搜索预算为 32，内层前瞻关闭，保留完整电路的真实总层数。选定两个映射后才执行原 SA 参考、`Hinit = 0` 和 `Hinit = 2` 三组完整编译，完整编译均保持动态 `H = 8`。最终整电路结果不参与初始候选选择。
- 每任务从子进程启动起总限时 600 s，包含共享 SA、两组初始选择和三次完整编译；并非每个配置各有 600 s。排队等待不计入该限时。新 32 项采用三个独立单线程工作进程并行，旧先导串行运行；两个阶段的墙钟计时不合并为速度结论，并行资源竞争属于新阶段的观测时间。
- 三个配置、三个种子均完整且通过有效性检查的 36 个电路进入主汇总。先在每电路内平均三个种子的对数保真度，再在电路间求几何保真度；批次先在种子间平均，再跨电路取算术均值。各种子不是独立电路。
- 共 5 个任务超时：旧 `ising_n42` 的种子 1、新 `qft_n29_transpiled` 的种子 2、新 `ising_n98_transpiled` 的三个种子。不完整电路的已完成种子可作描述性记录，不进入完整 36 电路均值。

新增 32 项的独立结果见 [new32_analysis.json](../../ZAC_zzx/results/initial_lookahead_v1/dynamic39-missing32-h0-h2-sa-k4-rho07-b32-seed012-p3-v1/new32_analysis.json)。跨阶段源码及算法等价性审计见 [postrun_analysis_provenance.json](../../ZAC_zzx/results/initial_lookahead_v1/dynamic39-missing32-h0-h2-sa-k4-rho07-b32-seed012-p3-v1/postrun_analysis_provenance.json)；映射选择统计见 [mapping_choices_analysis.json](../../ZAC_zzx/results/initial_lookahead_v1/dynamic39-missing32-h0-h2-sa-k4-rho07-b32-seed012-p3-v1/mapping_choices_analysis.json)。初始化结果由[独立生成器](generate_initial_lookahead_extension_values.py)核对全部预定记录后导出，不能合并到原主结果或动态对照的数值文件。

## 8. 参数配置与编译计时

参数与严格串行计时采用同一预定 12 电路清单。ZAC18 按量子比特数分为不超过 32、33–64 和超过 64 三层；QMAP 沿用双比特门数三层。每层按规范化 SHA-256、文件名排序选前两项。

| 来源与层级 | 电路 |
|---|---|
| ZAC，不超过 32 比特 | `ghz_n23`、`seca_n11_transpiled` |
| ZAC，33–64 比特 | `ghz_n40_transpiled`、`ising_n42` |
| ZAC，超过 64 比特 | `ghz_n78_transpiled`、`ising_n98_transpiled` |
| QMAP，不超过 300 个双比特门 | `4gt11_84`、`4gt5_76` |
| QMAP，301–1500 个双比特门 | `squar5_261`、`adr4_197` |
| QMAP，超过 1500 个双比特门 | `clip_206`、`hwb8_113` |

参数配置比较包括编码评价预算 192/1152、候选阱数与分配数 `(4,2)/(10,8)`、前瞻上限 2/4、前瞻权重与衰减因子 `(0.2,0.5)/(0.35,0.6)`。括号内两参数成组调整，故称参数配置比较，不作单因素效应解释。原始记录见 [sensitivity.csv](../../ZAC_zzx/results/paper_zh_v2/sensitivity.csv)。

严格计时在 14 核 Apple M4 Pro、24 GB 内存、macOS 26.6.2 上执行，Python 为 3.10.19，AppleClang 为 21.0.0。原生内核使用 C++17 Release，关闭 OpenMP 和快速数学优化；各编译器为原生单线程实现，串行运行。每方法在各基准集上进行一次不计入统计的预热，再对每电路固定种子 0 重复三次。计时对比的是各实现的端到端编译成本，不是消除实现语言差异后的算法复杂度。

逐电路时间使用三次运行中位数；正文的绝对时间再取 12 电路中位数，相对时间比先逐电路配对，再取几何均值。完整计时记录见 [runtime.csv](../../ZAC_zzx/results/paper_zh_v2/runtime.csv)。搜索内核中的嵌套计时不重复相加；物理重排时延不计为主机编译耗时。

## 9. 五档前瞻层数的补充比较

该比较沿用第 8 节运行前确定的 12 电路清单，不按新增结果挑选样本。配置为 `H = 0, 1, 2, 4, 8`，每个配置使用遗传搜索种子 0、1、2，共 180 个电路–配置–种子记录。初始化仍为固定种子的层序加权模拟退火；重复运行不代表更换初始布局。搜索预算、候选存储位域、物理模型、前瞻权重与规模相关的预算收缩规则保持一致。`H` 是层数上限，不是每个边界都实际预测的层数。

- **复用与新增。** 只读复用 96 条既有记录：12 电路的 H=0/H=8 三种子记录，以及 H=2/H=4 的种子 0 记录。新增 84 项仅补齐 H=1 的三个种子及 H=2/H=4 的种子 1、2，不重跑已完成的质量实验。旧记录来自相应历史提交；冻结源码比对确认其实际编译、放置、评分和原生后端一致，未使用的 H=0 配置注册项差异不改变所复用 H=2/H=4/H=8 的执行路径。
- **执行与验证。** 新增任务使用冻结源码、同一 ABI 9 原生后端及真实 ZAIR 验证器，最多两个单线程工作进程，单项限时 600 s、内存上限 3 GiB。84 项均完成物理执行，完整 180 条记录的指令、门序列、层序、非目标交点和占位校验通过，无超时。新增任务的并发墙钟时间不用于速度结论，也不混入第 8 节的串行计时。
- **模型适用范围。** `clip_206` 与 `hwb8_113` 在各 H、各种子下共 30 条记录超出原线性相干模型适用范围，保真度保持空值，物理执行记录完整保留。不以零、其他评分模型或替换运行填补。其余 10 个电路在五档配置下均有有效评分，其中 ZAC18 六个、QMAP154 四个。
- **追加式续跑。** 最初 23 项执行后，额外的质量检查误将其中两条物理成功但模型域外的记录标记为运行错误。[续跑协议](../../ZAC_zzx/results/horizon_extension_v2/continuation_v1/protocol.json)固定原 23 条回执与原始输出的哈希，追加两条独立分类说明，只执行剩余 61 项。原错误回执、已封存驱动和数据未重写；原 scorer 的域外标记与空值语义未改变。
- **表 IV 的统计口径。** 在五档 H、三个种子均有效的同一 10 电路集合上，对保真度和完整 ZAIR `rearrangeJob` 批次数分别取三次运行中位数，然后逐电路相对 H=8 求比，再跨电路取几何均值。表中每一行、每一列均使用相同的电路分母。该集合不替换图 7 的 39 电路 H=8/H=0 对照；表 IV 也不混入旧单种子参数记录的时间比。

[独立生成器](generate_horizon_extension_values.py)逐项核对 180 个身份、84 个新任务回执、96 个复用 manifest、配置及源码哈希，重新计算共同集合和配对比值，导出[数值宏](../horizon_extension_values.tex)、[逐电路数值](../paper_horizon_extension_values.json)与[来源清单](../paper_horizon_extension_provenance.json)。`--check` 只读验证，不修补缺失输出；`make paper` 与 `make paper-check` 均执行该检查。主结果文件与初始化前瞻扩展均保持不变。
