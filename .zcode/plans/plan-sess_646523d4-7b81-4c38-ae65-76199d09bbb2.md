# ZAC_zzx 完整计划 v4：2q 轮次 + 驻留（不放回）+ GA 分相位着色适应度（三层前瞻）

## 一句话
以 ZAC 为基座新建同级 `ZAC_zzx/`：轮次 = 2q 门 ASAP 层（ZAP 分离调度式，1q 门挂靠父层在座位上执行）；激发区原子默认驻留，每边界做 STAY / RETURN 决策（RETURN 落位按笔记三方案：原位/就近/伙伴位）；放置由 GA + 分相位着色适应度引导，**前瞻分三层：精确窗口（下一换位）→ 下次使用锚点 → 座位需求与拥挤聚合**。已吸收三路对抗审计（正确性/模型/实验）。

## 适应度 v4 —— 前瞻怎么考虑（本版核心改动）
驻留改变了决策的"影子长度"：留在原座的原子要一直坐到下次使用；参与者做完门也**留在门位上闲放**。所以门位选择和 STAY/RETURN 决策都必须看见未来。分三层，误差越大的层权重越低（折现）：

```
F = w_batch·(χ(B_L) + χ(O_{L+1}))                【第1层·精确】两相位各自着色
  + Σ√dmax(B_L) + Σ√dmax(O_{L+1})                【第1层·精确】批内最长腿
  + γ0^(r(q)-L-1) · √d(pos_after(q), anchor(q))  【第2层·估计】下次使用前瞻
  + λ_seat · Σ_kept hit(s)·2^(-Δr)               【第3层·估计】座位需求（时间折现）
  + κ · max(0, occ + demand_W - θ·cap)           【第3层·估计】拥挤梯度（软容量）
```

**第 1 层（精确，零误差）**：B_L = 本边界腿（RETURN/强制逐出，back 相）；O_{L+1} = 下一轮入区腿（含参与者区内短移，out 相）。两个时间窗分开着色——审计实证混合着色既漏计（跨相合色物理不存在）又多计（跨相冲突边无意义）。

**第 2 层（下次使用锚点，每步算一次）**：对每个原子 q，r(q) = 下次参与 2q 门的轮次（ASAP 调度已知，一次后向扫描预计算，零成本）；anchor(q) = 下次搭档的**当前座位**（搭档在激发区）或**存储原位**（在存储区）。项 = 按轮次距离折现的 √d(决策后位置, 锚点)：
- STAY 非参与者：pos = 原座 → 衡量"闲放到下轮后要走多远"
- RETURN：pos = 指派存储位（C3 伙伴族匹配天然把位选在搭档附近，此项与之互相印证）
- 门位菜单基因：pos = 门位 → 原子做完门就坐在这里，**门位本身要为下次使用占好位**（这是 ZAC 原版 dis3 项的推广：dis3 只管下一层的复用搭档，这里覆盖所有有后续使用的原子）
- 该项**统一取代** dis3 与 α 两个重复项（审计指出二者信息重叠）；γ0 默认 0.5，消融定参
- 误差分析：搭档可能也动（锚点陈旧），但本套件实测 inter-use 仅 1-2 轮（ising=1、qft≈2、串行=1），折现后远轮噪声被压住——前瞻恰恰在最常用的距离上最准

**第 3 层（聚合感知）**：座位需求项从"计数"升级为**时间折现命中**（挡住下一轮要用的座位比挡五轮后的更糟：前者马上逐出付 2 腿）；拥挤梯度给容量阀装上软坡度（占用 + W 窗口需求超出 θ·容量即罚，θ=0.9），让"留谁"在触阀之前就有梯度可循。

**可选 rollout 档（lookahead="rollout"，默认关）**：用"冻结的第 L+2 轮菜单估计 + 全 STAY 假设"近似再评估一个换位（B̂_{L+1}+Ô_{L+2} 着色），近似两步推演；约 2× 适应度开销，菜单每步只生成一次（不随染色体重算，避开审计 F4 的循环依赖坑）。与默认 anchor 档做对照消融，值不值由数据定。

**标定**（沿用 w_conf 非单调的教训，全部 3 个哨兵电路上扫）：γ0∈{0, 0.25, 0.5, 1}（**γ0=0 即无前瞻对照，隔离前瞻价值**）；λ_seat、κ、θ 同法。全部 √μm 计价。

## 决策模型（每个边界，激发区每个原子）

| 原子身份 | 默认 | 备选 | 实现 |
|---|---|---|---|
| L+1 轮参与者 | STAY：入区腿=区内短移到门位（菜单基因已定） | RETURN | 决策基因(ga)/解析规则(penalty) |
| 非参与者、有后续 | STAY 原位闲放（0 腿） | RETURN | 同上；RESEAT 仅 A2 消融（搭档稳定才移，K≤3，默认关） |
| 死驻留者 | STAY（原生编译器同款并赢过） | — | 仅容量压力逐出 |
| 挡路者（座位被 L+1 门位需要） | 强制 RETURN（硬排除兜底） | — | 解码器 |
| 容量不足（保留座+2×门数>140 对） | 按下次使用轮次降序强制 RETURN | — | 容量阀 |

**RETURN 落位三方案（笔记 :123-131）箱式化后最小权匹配**：C1 原位族（±自由位箱，防原位被占）｜C2 就近族（当前座位最近存储位±箱，省本次）｜C3 伙伴族（下次搭档附近箱，省未来）。每族必须扩成自由位箱（审计实证 nearest_storage_site 每半行每列只回一位，同列驻留者会撞）；匹配复用 is_empty_storage_site + common_site + ratio-3 箱（vmplacer.py:336-358, 443-450）。**RETURN 目标位每步一次匹配定为常量**（全体潜在回返者同时匹配到互异自由位），染色体选 RETURN 即用其指派位——可按 (原子,选项) 缓存边界腿（审计 F6 的编译时间主要来自每染色体重做匹配）。

## 实验与验收（数字全部来自审计实测）
动机池：回程相占 38.9-54.2%（wstate 54.2%、bv_n14 45.5%、ghz 42.8%）；消 25% → 0.851，50% → 0.743；1q 不构成地板（搬运占 99%）。

梯队：A0=B 基线 → A1=惰性+penalty → A2=A1+RESEAT → A3=决策基因+GA+分相位适应度 → A3'=A3 混合适应度（隔离分相位修正价值）；A2→A3 增益 <2% 则默认配置取 A2。

消融（≈40-50 分钟）：5 全套（主/none+penalty 同会话重跑 B/none+ga/stay+penalty/reuse+ga）+ 前瞻标定扫（γ0 4 值 × 3 哨兵 + lookahead=0 与 rollout 对照，qft_n29/ising_n98/ghz_n78）+ RESEAT 开关（qft_n29, ghz_n78）+ horizon 3 值（同 3 哨兵）+ A3'（qft_n29）。

种子稳健性：3 种子 × 3 哨兵，极差 ≤0.03。

验收：
1. 回归 = 规范化指令流恒等（非字节）：none+penalty ≡ 同会话 B；13/18 与冻结 ZAC truth（ZAC/result/zac/repro_fixed）运行时浮点恒等
2. 验证器 8 查全绿
3. 时长：geomean 门槛 ≤0.92 / 目标 ≤0.85；串行族 geomean ≤0.85；qft_n18 ≤0.85、qft_n29 ≤0.90；单电路 ≤1.05；批数 ≤1.25×B
4. 编译：单电路 ≤3× 同电路 A（A 全套实为 271.8s）；全套 ≤15 分钟
5. 保真度只报五项分解（transfer/coherence 是时长单调函数，不设线；脚注 0.625 vs 52μs 不一致）
6. 决策分布表 + 占用峰值/140 + **前瞻各层贡献表**（γ0=0 与默认的逐电路差值）
