# 前瞻术语与符号统一

## 修改目的

作者指出“最大视界”等术语无法在首次阅读时直接理解，且正文、表格与图形存在多套符号。本轮只调整中文稿的解释与记号，不改变算法、参数、候选规则或实验数值。

## 统一规则

| 对象 | 当前写法 | 阅读与计数约定 |
|---|---|---|
| 动态前瞻上限 | 前瞻层数上限 `H` | 当前双比特层之后最多预测的层数，不包括当前层；在第三章总体框架先用文字和0/8例子定义 |
| 动态实际层数 | `h_ell` | 不超过 `H`，可因剩余层数、规模预算或衰减停止条件而缩短 |
| 初始化前瞻 | `H_init` / `h_init` | 以首个双比特层为起点，计数仅指额外层；上限0只评价首层，上限2最多评价首层及后续两层 |
| 无未来层 | `h_ell = 0` | 包括设定上限为0或电路已无后续层；未来层求和与末端项均约定为零 |
| 整体配置 | 粗体 `s_ell` | 全部原子的位置、占位与时钟；正文、算法和图3–5一致 |
| 单个存储阱 | 细体 `s_1`、`s_2` | 表示真实存储光阱，避免与整体配置混用 |
| 求解预算 | 枚举上限、评价预算、种群规模、迭代代数等具名列 | 不再用一次性字母元组作为表头；原数值、触发条件和重叠取严规则不变 |
| 存储位分配数 | `K` | 在实际解释匹配过程时引入，贡献段不提前堆放符号 |
| 图中一次性映射标签 | Candidates / Selected layout / After staging | 以短英文词组替代只在图中出现的映射符号；物理几何不变 |
| 电路规模与参数比较 | 双比特门数 `N_2`；保真度比、编译时间比 | 与背景模型记号一致，表注保留相对默认配置的统计定义 |

固定的四分之一接受比例用文字表达，不再单列符号。图4图注补充门位基因的数字及正负上标含义。全文术语规则同步至 `06_terminology_ledger.md`。
