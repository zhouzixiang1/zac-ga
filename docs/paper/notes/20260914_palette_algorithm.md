## 配色

在相同四张原生矢量图上比较了三套方案，当前采用A：靛蓝核心、浅蓝存储区和浅金纠缠区。B为深蓝/玫瑰色，C为蓝绿/梅红；三套两页对照PDF均保存在本轮构建目录。

| 角色 | 线条/强调色 | 填充色 |
|---|---|---|
| GA-LK、驻留基因、结果均值 | `#332288` | `#F0EFF8` |
| 存储区 | `#4477AA` | `#EDF4FB` |
| 纠缠区 | `#997700` | `#FFF6D9` |
| 前瞻预测 | `#AA3377`，虚线 | `#F7EDF3` |
| 不可行交换/路径 | `#CC3311`，虚线及叉号 | 无 |

配色参考 [Paul Tol 的定性配色及浅色背景建议](https://sronpersonalpages.nl/~pault/)（2026-09-14访问），按图中角色调整了组合与填充亮度。它是针对本稿的适配组合，不宣称等同于某套原始无障碍验证方案。颜色之外继续以区域名称、实虚线、空心/实心点和点形区分语义；实际执行保持深灰实线。

## 算法

新版 `sections/03_algorithm.tex` 与 `sections_en/03_algorithm.tex` 在第三章开头引入，均为18步、单栏9pt。框架图保留全编译流程；算法1说明单层联合求解的调用和选择顺序：

- 构造编码及匹配，生成完整候选的当前执行批次。
- 分别记录当前可执行性与未来预测可行性，缓存评价并推进搜索。
- 搜索后局部调整及重评，再确定参照、执行准入和排序。
- 保留参照及预测失败时的当前代价回退；无当前可执行候选则报告失败；只提交当前层。

适应度、驻留参照与四分之一准入的完整定义保留在第三章正文。英文伪代码采用短操作语句，避免长句折行。此前退役算法仍保存在补充材料中。
