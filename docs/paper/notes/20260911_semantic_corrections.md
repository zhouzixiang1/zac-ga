## Overleaf 导出

使用现有项目与原 Git 历史，先核对远端提交，再运行 `scripts/prepare_overleaf_sync.py --chinese-only --expected-remote <已核对提交>`。六个当前派生输入原字节复制到在线项目的 `paper_exports/default_initial_v1/`，仅适配中文入口的两处输入路径和图3的生成PDF路径。英文专属文件和在线额外文件保留。

提交前从独立 checkout 编译中文入口，核对页数、引用、数值与本地逐页渲染；推送后以 `git ls-remote` 验证实际远端提交。最终提交号及包校验记录保存在本地验收目录，避免将生成日志写入云端项目。
