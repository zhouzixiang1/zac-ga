# 当前论证主线

2026-09-14。两语言采用同一论证顺序，摘要与关键词受单独保护。

分区架构保护空闲原子，但门位、驻留和回迁位置共同改变当前及未来的物理执行条件。
GA-LK比较完整联合候选，先构造当前可执行批次，再从候选完成后的配置预测多层损失。
遗传搜索在这一评价下选择方案，初始化将同一物理评价依据用于执行起点。
正文包含四图、一表和一个引领算法。算法从完整候选贯穿当前执行评价、未来预测、搜索后准入与当前层执行，帮助读者把各小节连接为同一过程；预测失败不等于当前方案不可执行。
