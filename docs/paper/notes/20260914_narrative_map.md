# 全文行文逻辑与证据脉络

对应2026-09-14第三章主线修订及上传前视觉审核后的中英文稿。

全文的核心判断是：**当前放置既决定本层的执行代价，也决定后续门层的执行起点。因此，门位、驻留和回迁位置要作为完整方案比较，并从方案执行后的配置评价未来损失。**

## 从问题到方法

摘要浓缩问题、方法与主要结果。引言把这个问题逐步展开：先由中性原子硬件及分区架构的优势引出编译需求，再通过驻留与回迁的物理得失缩小研究范围。驻留节省转移，却增加空闲受激并占用门位；回迁改变下次交互的输运起点。由此产生两种相互联系的依赖：位置决策之间的依赖，以及当前门层与未来门层之间的依赖。两项贡献分别回应这两种依赖。

第二章提供理解和解决问题所需的共同基础。SLM/AOD的职责、行列关系、非目标交点和占位约束说明，移动距离不能直接代表实际执行代价。保真度模型把阱转移、受激和相干损失放在同一尺度上；驻留与往返的两因子算例说明，最合适的选择会随复用间隔改变。相关工作最后明确本文要补足的跨层评价关系，为第三章的方案定义和评价方法作准备。

第三章首段是全章的入口：先给出当前损失与后续影响的统一决策原则，再串起完整候选、执行后配置、多层前瞻、遗传搜索和当前层推进。后续四节依次回答：

| 小节 | 必须让读者理解的内容 | 为什么需要下一节 |
|---|---|---|
| 联合放置建模 | 门位与驻留编码加回迁匹配构成完整候选；固定门层给出相同的比较对象 | 目标位置本身无法说明分批、中转和未来起点的代价，需要物理评价 |
| 跨层物理损失评价 | 当前批次产生损失和执行后配置；未来层继承该配置，逐层形成预测损失 | 有了完整对象和评分，才能讨论怎样寻找更好的方案 |
| 遗传搜索与初始布局 | GA探索联合空间，局部调整后重评，再执行参照、准入和排序；初始化复用物理评价 | 选出的方案还需要与真实指令和统计口径衔接 |
| 物理约束下的编译输出 | 评价与输出共用路由和时序规则，形成可执行指令及保真度、批次和时延 | 这些输出成为第四章的测量对象 |

初始化放在共同评价方法之后介绍，其逻辑身份是该评价依据在第一层之前的应用。正文先建立“比较什么、如何比较”，再介绍交叉、变异和预算，避免读者先读搜索操作却不知道其目标。

## 从方法到证据

第四章首先集中比较设置，使后文每个结果的参与配置、样本和聚合口径可追溯。随后的论证逐步回答四个问题：

1. **整个编译器是否有效？** 表I给出两套电路、两种基线上的总体质量与批次结果，逐电路胜负说明平均提升的分布。
2. **物理收益从哪里来？** 损失分量及QFT短例说明，减少转移和相干损失可以补偿额外受激损失。这直接验证第三章为何采用统一物理尺度。
3. **核心设计分别起什么作用？** 固定起始映射的前瞻比较支持跨层评价；同一联合空间内的GA/贪心比较支持搜索方式。二者不是可相加的主收益拆分。初始化比较进一步检验早期执行评价与遗传搜索在起始映射上的作用。
4. **需要看多远、搜索多少？** 图4说明近期交互提供主要平均收益；预算对照说明候选展开量可以调节计算投入，并在所测范围内维持相近质量。

结论回到引言的问题：位置应由其引起的跨层物理执行损失评价，近期信息和有限候选使这一权衡能够在有界搜索中实现。结论不再次罗列全部模块和实验数字。
