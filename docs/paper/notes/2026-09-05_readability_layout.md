# 中文稿可读性与末页排版修订

本轮从提交 `196ffc4` 继续。用户要求解决表III、IV及末页正文排版，并减少实验纪要式叙述与空泛过渡词。本轮不新增实验、不调整选例、不改变数值、基线范围或模型。

## 文字处理

采用学术润色技能中的算法论文规则，保持中文IEEE语体：先说明设计理由，再给定义与形式规则；不以增加术语难度代替学术性。

- 引言直接说明硬件条件、编译选择及其物理影响，删除重复设问与“进一步”式递进。
- 背景按门执行、输运约束和跨层依赖解释实例，直接指明原子、阱位和轨迹。
- 方法在联合编码、冲突图、有限视界和候选排序前补充设计理由。单射解释为一阱至多一原子；词典序解释为先比较首项，同分时依次比较后续项。
- 结果按比较发现组织段落，保留共享参数、相同目标与预算、样本筛选和计时条件。删除“分别考察……作用”等对实验安排的重复说明。
- 讨论围绕驻留损失、具体存储位和后状态评价解释方法，删除对整套实验分类的重复总结。
- 清理只承担衔接作用的“进一步、由此、因此、与此同时”等表达。物理或数学条件中的“同时激活”“同时满足”“同时生效”保留；常见连接词并非一概禁用。
- 按作者后续反馈，清理“不必、未必、不单独、而不是”等劝告式或预先反驳式表达。例如将“搜索资源的配置不必在所有电路上保持相同规模”改为候选预算、视界上限与衰减权重各自作用的事实陈述；占位冲突直接说明发生于哪一个静止原子和哪一条轨迹，以及如何消除。算法中的不可行条件、回退和非全局最优界限保留。

示例：

| 路由感知放置进一步把轨迹兼容性与批次时延纳入A*代价。 | 路由感知放置把轨迹兼容性与批次时延纳入A*代价。 |
| 已完成当前物理状态转换评价及适用的有限视界状态推进的候选。 | 已完成评价的物理可行候选集合。评价包括当前状态转换，以及启用前瞻时的未来层预测。 |
| 两项比较分别考察未来信息的作用，以及在同一决策空间内选择搜索策略的影响。 | 删除重复分类句；相邻两句直接报告有限视界和同目标、同预算搜索策略的比较结果。 |
